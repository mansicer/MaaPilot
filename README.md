# MaaPilot

让 AI 助手帮你玩《明日方舟》：每天定时自动做日常，练干员、合材料、打关卡只要跟它说一声。
底下用 [MAA](https://maa.plus) 操作游戏，由 [Claude Code](https://claude.com/claude-code) 里的 agent 判断做什么。

## 开始

需要：一台 Mac、一个安卓模拟器（装好明日方舟并登录过）、Claude Code。

```sh
cd MaaPilot
claude
```

第一次打开时屏幕上会提示还没设置，随便说一句（比如"开始"）就进入设置：助手会带你确认模拟器、装好 MAA、问你日常几点跑、做哪些，十几分钟就好。
第一次启动时 Claude Code 会问要不要信任这个文件夹，选信任（定时日常要用到）。之后每次打开，直接说想做的事：

- "现在跑一次日常" / "今天做了什么"
- "把遥练到精2" / "给能天使专三"
- "合 10 个聚酸酯组"
- "打一次剿灭" / "帮我做泥岩的模组任务"

## 放心的地方

- **合成玉、源石**每次花之前都会问你；助手动过游戏之后没经你同意就少了，程序会发现并停下（你自己在游戏里花的不算）。
- 练干员、合材料这类花费，第一次会先报数，你同意了才做。
- 其他拿不准的事，第一次遇到时问你，之后按你说的办。
- 账号数据只存在本机的 `private/` 文件夹里，不进 git。

开发者说明见 `docs/`。
