# maapilot-battle：打关卡

**只有 3 星算通关**，2 星要重打。每次战斗后看结算页核对星数。剧情直接跳过（右上"跳过"，再确认）。

## 先分清是哪种

| 情形 | 做法 |
|---|---|
| 已经三星通关过的关，刷材料 | `maapilot maa fight <关卡> --times N` |
| 没打过 / 没三星的关 | 找作业，`maa copilot` |
| 剿灭 | `maapilot maa annihilation` |
| 模组任务 | 读任务要求，拆成具体的关和条件，再按上面做 |

先 `maapilot data stage <关卡>`：理智消耗、今天开不开、主要掉落。理智不够就 `state sanity` 看看，告诉用户要等还是用理智液（见 `maapilot-daily` 的理智液规矩）。**不用源石回理智。**

## 刷已通关的关

`maapilot maa fight <关卡> --times N`（不写 `--times` 就打到理智用完）。结果里有 `times_done`、`sanity_used`、`drops`。
- `not_open`：今天不开（芯片本、资源本按星期开），换一关或改天。
- 打不了代理（关卡页没有"代理指挥"或没勾上）：这关没三星通关过，按下一节打一遍三星。
- `offline`：掉线或维护，按 `maapilot-recovery`。
- `proxy_failed`（`note` 里写着几场代理失败）：代理指挥没打赢，这一场理智全退回、没掉东西，MAA 照样报"完成"。偶尔一次不用管；
  同一关连着失败（或一批里失败过半）说明那次三星记录不稳：用作业重新三星打一次（`copilot find` → `maa copilot`），代理会改用新的这次记录，再接着 `maa fight`。
  一时打不了就换同样掉高级材料的另一关（活动关按 `calc event` 的顺序往下挑），**不要因为代理失败换去掉低级材料的关**。把这关代理不稳写进目标笔记。

## 打没打过的关：用作业

1. **找作业**：`maapilot copilot find <关卡>`（活动关也行，如 `YW-4`）：按热度列出作业站上这关的作业，每份标出要哪些干员、用户有没有、
   每人差什么（`gaps`，如"要技能2 专3，现在专0"）、查不了的（`unknown`），用户都有的排前面。一份的细节用 `maapilot copilot show <编号>`。
   不要自己写脚本去查作业站。作业站查不到就请用户在网页 https://prts.plus 上挑一份，把编号告诉你。
2. **挑作业**：先挑 `all_owned`（人都有）的，差得少、热度高的优先。**作业写的练度要求常常偏高**（作者用的是满练度）：
   人都有、只是练度不到的，直接加 `--ignore-requirements` 实打一次，打输了理智全额返还；这样往往能三星（昨日海 YW-4～YW-7 就是这样打下来的）。
   `--ignore-requirements` 还被 MAA 拒绝时，`maapilot copilot strip <编号>` 写一份去掉要求的本地作业，用它的路径跑。
   **要求不满足时（缺人、练度或模组不够）由你自己决定**打不打、怎么打，不用先问用户，也不用先打演习：可以借助战（`--support`）、
   照样开打（`--ignore-requirements`，MAA 不按要求挡下），或者换一份作业。决定了就记一句理由（缺什么、为什么觉得能打）。
   但**要求不满足、打了又没成**（失败或不到三星）时就停下，不再换作业重试：把这份作业缺什么、怎么打的、输在哪（截图）告诉用户，
   请用户来判断怎么办（换作业、补练度、加成长期目标、自己手动打）。无人值守时写进汇报"要你决定的事"。
   作业的要求都满足、却没打成的，可以换一份作业再试。
3. **进编队页**：把游戏停在这关的关卡页，**再点"开始行动"进编队页**（从关卡页、剿灭页直接启动时 MAA 会跳过编队）。
   主线：首页"终端"→"主题曲"→ 章节 → 地图上左右滑找关卡号，点开。活动关从终端的活动入口进。每一步 `screen shot` 看。
4. **打**：`maapilot maa copilot maa://<作业编号> --formation`（`--formation` 让 MAA 按作业自动编队）。本地作业文件写路径。
   其他参数：`--formation-index N` 用第几个编队；`--add-trust` 空位按信赖从低到高补人；`--ignore-requirements` 不管练度要求；
   `--support 1|2|3` 借助战（1 只缺一人时借；2 缺一人时借、否则借 `--support-name <干员>`；3 缺一人时借、否则随便借）；`--raid raid` 打突袭。
5. **核对**：打完马上 `screen shot` 看结算页：三星（三颗星）才算。`maa copilot` 的结果里没有星数，命令返回时结算页可能已经过去了：
   截图不是结算页就回到这关的关卡选择页，看关卡号旁边的星星（三颗亮的才算），或点开关卡看"代理指挥"能不能勾选（能勾就是三星过了）。
   两星或失败按第 2 步的规矩：要求都满足的换一份作业，要求不满足的停下请用户判断。
6. 打过三星以后这关就能代理，以后用 `maa fight` 刷。

## 剿灭

`maapilot maa annihilation`（默认当期剿灭、打 1 次；`--times N` 打几次）。结果里 `orundum_gained` 是这次拿的合成玉，`weekly_capped` 为真说明本周合成玉已经拿满，别再打（日常也会自动跳过）。剿灭能代理的前提是这张图以前 400 杀满过；没满过就找剿灭的作业，用 `maa copilot`。
剿灭拿的是合成玉（增加），不算花费。每次打要消耗理智。日常里剿灭连着 2 次没打成（多半是不能代理），这周的日常就不再打，汇报里会提；要用户决定是找作业打一次，还是先不打。

## 推主线

一关一关按上面"打没打过的关"做：每关找作业 → 打 → 核对三星 → 下一关。打不过的关停下，告诉用户缺什么，问要不要加成目标。一次推多少关先问用户（理智有限）。

## 模组任务

干员页的模组入口里能看到模组任务，一般两步：一个关卡条件（例如"在某关中部署该干员并三星通关"或"使用该干员击倒 N 个敌人"），一个关卡挑战。
1. `maapilot data operator <干员>` 的 `modules[].missions` 是每一步任务的原文（`stage` 是要打的关），`unlock` 是解锁要的精英化和等级。
   拆成"在哪关、带谁、满足什么条件"；数据里没有（新模组）再去模组页截图读。
2. 找能带上这个干员的作业（或在用户同意下自己编队）；条件是"部署该干员"时，作业里没有他就不算。
3. 打完回模组页看任务是否打勾。两步都完成后才能解锁模组（花费见 `maapilot-training` 的模组部分）。

## 问用户的情形

- 打不过、缺干员或练度时：要不要加成长期目标；
- 要用理智液、而记忆里没有用户的说法时；
- 推主线一次推多少、要不要为某关花理智；
- 要求不满足的作业打了没成（第 2 步）：请用户判断怎么办。

## 记住什么（写进用户偏好 private/memory/）

- 哪份作业在这个账号上打成了三星、哪份不行（关卡号 + 作业编号），写明日期。
- 某关的导航怎么走、哪关打不了代理。
- 用户对推图、剿灭的偏好（"剿灭每周打满就行""别为推图用理智液"），写明是用户哪天说的。
