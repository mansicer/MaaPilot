# maapilot-memory：整理用户偏好

偏好是用户亲口说的话。整理只是让记录好找，不替用户改主意。文件格式见 AGENTS.md「用户偏好」。

## 什么时候做

- 日常结果里有 `memory_tidy: true`（离上次整理满一个月）：收尾（`daily done`）前做。不到一个月就没有这个字段，不用提。
- 用户说要整理：随时做。

## 怎么做

1. 读 `private/memory/MEMORY.md` 和目录里每个 `.md` 文件。
2. **可以直接改的：**
   - 目录对不上：指向不存在文件的行删掉，没进目录的文件补一行。
   - 说的是同一件事的几个文件：合成一个，用户的原话和日期都留着，删掉多余的文件，改好目录。
   - 账号、昵称、UID、token，还有会变的数（仓库有多少）：去掉，这些本来就不该记。
3. **要用户决定的（不改，先记下）：**
   - 互相矛盾的说法，看不出哪句是后来改的主意。
   - 看起来过时的：临时提醒、已经结束的活动、提到的功能不在了。
   用户在场就问，一次一件事。用户不在（定时日常）就写进总结"要你决定的事"，原文不动。
4. `maapilot memory tidied` 记下这次整理的时间，什么都没改也要记。要用户决定的事还没答复，也记。
5. 交代结果：合并了什么、去掉了什么。什么都没改就不用提。

用户答复后按答复改文件，文件里写清是用户哪天说的。
