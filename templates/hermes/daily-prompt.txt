这是 Maa 独立 profile 的重复定时日常。先读 AGENTS.md、docs/harnesses/hermes.md 和 maapilot-daily 技能。cron 中不管理或创建定时任务。
本轮不重新 setup；若设置缺失，立即返回需在主会话继续首次设置的阻塞说明，不询问、不修改 setup.json。
先检查是否有未收尾日常，按技能接着收尾；否则执行 maapilot daily run --trigger schedule。后台进程必须在当前轮次持续 process_manage wait/poll 到 status=exited；单次 timeout 只表示等待窗口结束，不是进程退出。正常运行期间静默。
按技能处理接管、目标、领奖励和对账，并尝试 daily done。成功时最终答复使用与 daily done 相同的固定格式简报，可用下面的只读命令提取；不要发送完整程序报告。启动失败、部分失败、无法恢复或收尾失败时，也必须及时给出一条真实的结果，说明已做、未做和下一步，不等收尾成功才回复。
这是无人值守任务，用户不在场；不追问、不等待回答，未授权事项写入结果，合成玉和源石不花。
本轮只返回最终答复，不主动发消息；通知失败不能触发重跑游戏。
