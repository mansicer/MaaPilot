# maapilot-base：合成与基建

日常的基建换班、收菜、线索由 MAA 的基建任务做（`maapilot-daily`），这里管的是 MAA 不做的：加工站合成、制造站改产，以及用户点名要做的基建操作。

## 合成材料

1. **先算**：`maapilot calc craft <物品> --count N` → `steps`（按顺序：先合中间材料，最后合成品；每步材料、龙门币、在哪合）、`short`（合完还缺的基础材料）、`mood`（加工站心情总消耗）。
   `short` 不为空：缺的要刷，报给用户（或记进目标）；只能合一部分时说清能合几个。`mood` 超过加工站现在干员的心情时，要分几轮、中间换人（见「心情」）。
2. **花费**：目标里同意过的直接做；用户这次说"合 10 个聚酸酯组"时，一句话报花费（龙门币、用掉哪些材料）就做——但会吃掉别的进行中目标要的材料时先问。
3. **先试快捷命令，一步一条**：`craft` 只合点名的那一样，不会替你先合中间材料。照 `calc craft` 的 `steps` 从上往下，每一步
   `maapilot craft <物品> --count <数量>`（物品、数量是这一步的 `item`、`count`）；双芯片走制造站，芯片助剂走采购中心。
   **心情分批**：加工站的一步里，每批只合现在的驻站干员心情撑得住的份数（先截图看加工站房间里干员的心情；看不出就按每批最多约 24 点心情算，
   份数 = 24 ÷ 这一步每份的心情），不够就换一个心情满的干员再合下一批。心情不够时整批会失败，什么都没合。
   失败（`shortcut_failed`）看 `data.stage`、`data.done`（已经合了什么）、`data.shot`，接着手动做剩下的。
4. 做完 `state depot` 核对数量，告诉用户："合了 10 个聚酸酯组，用了 20 个聚酸酯、10 个固源岩……花了约 1 万龙门币。"

## 加工站手动合成

路线：首页"基建"（约 980,600）→ 基建总览（左上"进驻总览"）→ 点"加工站"（看不到就左右滑总览）→ 房间左下"点击进行加工" → 合成页（右侧有"加工份数"）。
1. 点中间的配方区（约 610,485）打开配方列表，左侧选"精英材料"分页（约 150,222）。列表会记住上次滚到哪：先往上滑到顶，再往下找。
2. 点配方名选中。配方卡上写"解锁"的是还没解锁（要先通关某关），告诉用户。
3. 设份数：+ / − （约 1073,288 / 1073,477），"最少"（约 1210,477）。大号份数数字常读不准，看第一种原料下面的"有/需要"来推算份数更可靠。
4. 点"开始加工"（约 1110,635），弹"获得物资"就点一下关掉。偶尔会多出副产品，正常。
- 右侧出现"不足""无法""上限"：原料或龙门币不够、或超过一次能合的上限，分几次合。

**合成顺序**：一次要合好几层时，**先合中间材料、再合成品**。所以一开始成品配方的原料显示 0/1、标红是正常的，照 `calc craft` 的 `steps` 从上往下合，合到它那一步原料就够了。

**心情**：加工站每合一份都要消耗驻站干员的心情，数量是配方卡左上角的那个数。心情不够时按钮不能点 / 提示心情不足：
- 在加工站房间里点进驻的干员位，换一个**心情满的干员**进来（进驻信息 / 换人页，心情是干员卡上的条或数字），确认后回来继续合；
- 一轮不够就合一部分、再换人、再合，多轮都可以；
- 换人会打乱 MAA 的基建排班，下次日常基建换班会自己排回来，不用管。别换走正在别处干关键活的干员（记忆里有用户的偏好就照办）。

## 双芯片（制造站）

双芯片 = 2 个芯片组 + 1 个芯片助剂，在 3 级制造站合，一个 1 秒。步骤（`craft` 快捷命令就是这么做的）：
1. 进一间 3 级制造站，点左下产物面板进生产面板，**记下原来的产物和生产份数**；有已完成的产物先"收取"。
2. 点右侧产物卡 → 产物选择，左侧"芯片"分页，找到要的双芯片（辅助 / 特种在最下面，要往上滑）。
3. 改产要确认两次：份数旁的小框"执行更改?"点 ✓（约 950,597），再是整屏"更改配方后将取消当前制造计划"点 ✓（约 842,494）。正在做的那一份进度会没了，这是正常代价。
4. 设份数、等产物卡显示"已完成"（OCR 可能读成"已克成"），收取。
5. **必须改回原来的产物和份数**。这一步最重要：改不回去就截图告诉用户，请他改回。

**芯片助剂**：采购中心"凭证交易所"里用采购凭证兑换。只在目标里报过（同意过）或用户这次说了要换多少时换；别的凭证用途先问用户。
采购中心里合成玉、源石的东西（礼包、源石交易所、时装）一律别点。

## 其他基建操作

- 用户点名的操作（换某人进某房间、改制造站产物、用无人机加速）：按用户说的做，做完说清改了什么。无人机加速不花钱，但先查记忆里用户怎么说过。
- 离开基建会弹"是否确认离开罗德岛基建？"，确认（约 842,495）。
- 回首页见 `maapilot-recovery`。

## 问用户的情形

- 合成会吃掉别的目标要的材料时；
- 目标之外要花采购凭证、别的凭证时；
- 要换走的干员正在别处干活、记忆里没有用户的偏好时；
- 制造站改不回原产物时。
