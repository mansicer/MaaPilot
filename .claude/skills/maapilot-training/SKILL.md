# maapilot-training：升级、精英化、技能、专精、模组

动手前确认花费有着落：目标里同意过的，或用户刚说"做吧"的即时任务（见 `maapilot-goals`）。

## 先试快捷命令

| 要做 | 命令 |
|---|---|
| 升级 / 精英化 / 升技能 | `maapilot op upgrade <干员> --elite 2 --level 1 [--skill 7]` |
| 专精（一次开一阶） | `maapilot op mastery <干员> --skill 3 --rank 1` |

成功时 `data` 有 `before`、`after`（升级前后的练度）。花了多少命令不算：动手前后各跑一次 `state depot`，对比着汇报。
失败（`shortcut_failed`）时看 `data.stage`（做到哪一步）、`data.done`（已经做了的部分）、`data.shot`（失败时的截图，用读图看），**从卡住的地方接着手动做**，别从头再来一遍（已经升上去的不会退回）。
退出码 2（参数写错、名字认不出）先改参数；4 是模拟器被占用，等一会儿。

## 手动操作的基本功

- 看：`maapilot screen shot`，读图；找按钮用 `maapilot screen ocr --find "<字>"`，点 `center`。下面的坐标是 1280×720 上的参考位置，**先截图确认再点**。
- 点完不会自动截图：每点一下都 `screen shot` 看结果再决定下一步。转场、加载时等一两秒再截。
- 回首页、处理弹窗见 `maapilot-recovery`。

**进干员页**：首页右侧的"干员"（约 941,335），或左上角菜单（约 270,38）里的"干员"。列表右侧是职业分页，找到名字点卡片。
第一次进某干员页会弹"角色档案"教程，点左上关闭（约 156,109）。
干员页：右上是等级面板（黄色大数字是当前等级，下面小字"/上限"，经验条满了显示 MAX）；"精英化"按钮在约 1000,275；技能区在右下，"RANK n"是技能等级。
做完回列表时**保持列表没加筛选**（右上筛选恢复成 ALL）：MAA 读干员是照当前列表扫的。

## 升级

1. 干员页点等级旁的"+"（约 1210,142），进升级页。
2. 要升到当前阶段满级：点上限那个数字 / "MAX"（约 1150,181）。要升到某一级：拖右侧那列数字（约 x=925，往下拖变大，一次约 4 级；上下相邻的数字点一下 ±1、±2）。
   左边"目标等级 LV n"在右边显示"计算中"时是旧的，等它消失再读。OCR 常把 7 读成 Z、1 读成 T，拿不准就多看一眼。
3. 点"确定"（约 1190,492）看消耗，再点"提升等级"（约 1170,605）。经验卡游戏自动选。出现"不足""无法"就停：材料或龙门币不够。
4. 升级结果页点一下屏幕回干员页；升级提示会短暂盖住等级数字，等它消失再读。
- 只能升到**当前精英阶段的上限**；精英化后等级回到 1。

## 精英化

1. 先把等级升到当前阶段满级。点"精英化"，进"是否晋升"确认页，看材料有没有标红 / "不足"。
2. 点确认（约 1080,655），会放一段动画，点几下屏幕跳过，回到干员页核对上限变了（精1 后上限变大）。

## 技能等级（1–7，所有技能共用）

1. 干员页点技能升级按钮（约 1200,400），弹"等级 X 到等级 Y"和材料。
2. 点确认（约 1125,616），每点一次升一级；到目标就返回。5 级以上要精1，7 级满后按钮变成"专精"。

## 专精（训练室）

条件：精2、技能 7 级；训练室 1 级只能专一、2 级到专二、3 级到专三。**一次只能练一个**，每阶要几小时（约 8 / 16 / 24 小时，协助者能缩短）。
1. 进基建 → 基建总览里点"训练室"（看不到就左右滑）→ 房间里左下的训练位（约 80,610）→ 训练计划页（左边有"协助者"）。
   显示"训练中"就是在练别人：不能开，告诉用户谁在练、大约什么时候好，记进目标笔记，下次再看。
2. 点受训干员头像（约 210,230）→ 选人页：右侧点职业分页，列表里找名字。在别的设施上班的干员卡片上显示"工作中"而不是名字，点一下看左边显示的名字。
   选中后点"确认"；弹"排班调整"就确认（把他从原设施调出来）。
3. 点要专精的技能的按钮（技能 1/2/3 约在 408,230 / 408,440 / 408,650），弹"是否专精该技能"：
   - 看确认框上的材料"有/需要"和时间，**认准这是专几**：不能超过目标的阶数；认不准就取消，截图告诉用户。
   - 缺 T3 以上的材料能合成：取消，按 `maapilot-base` 合出来再回来。缺基础材料：取消，记进目标等日常刷。
4. 点确定（约 1148,622）；取消在约 952,622。看到"技能专精开始"/"训练中"才算开了。
5. 记进目标笔记："MM-DD 技能3 专1 开始，约 X 小时"。练完后下一阶再开一次。用户在游戏里自己开的专精这里不知道，看到训练中就别打断。

## 模组

模组在干员页的模组入口（精2 且等级够了才出现）。先要完成模组任务才能解锁（任务怎么打见 `maapilot-battle`），再花模组数据块、数据增补条 / 数据增补仪和龙门币解锁、升级。
这些花费只在目标里同意过、或用户这次明确说了才点；页面上出现合成玉、源石的一律先停下问。

## 做完核对

- 等级、精英化、技能等级：`maapilot state op <干员>`（约一分钟）；很多干员一起核对用 `state box`（几分钟，读不到技能）。专精、模组读不到，以屏幕为准。
- 告诉用户结果和花费："遥升到了精2 1级，花了约 18 万龙门币、2 个聚合剂和 1 个辅助双芯片。"数从做前后各一次 `state depot` 的对比里来。
- 记进目标的"分解与进展"。

## 常见卡点

- **升级提示 / 晋升动画**盖着等级面板：等一两秒再读，别当成读错。
- **等级拨盘读不准**：多截一张；用拖动而不是狂点；实在不行就点 MAX 升满，只要不超过目标阶段。
- **材料不足**提示（"不足""无法"）：不要反复点，回去算账。
- **训练室在用 / 训练室等级不够**：记下来，告诉用户。
- **选人页找不到**：没精2、在别的设施"工作中"、筛选没清掉。

## 问用户的情形

- 花费不在目标里、用户也没刚说过要做；
- 专精确认框认不准是哪一阶；
- 训练室在练别人、要不要换（会打断别人的专精，一般不换）；
- 模组解锁 / 升级花费没说过时。
